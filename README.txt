TUIT LEARN — ONLINE LEARNING PLATFORM PROTOTYPE

How to run:
1. Extract the ZIP archive.
2. Open website/index.html in a modern web browser.
3. No installation or internet connection is required for the main demo (Google Fonts are optional).

Included demo features:
- Student dashboard with sample statistics
- Course cards and progress bars
- Upcoming assignments and study schedule
- Course modal with lesson completion interaction
- Simple knowledge-check quiz
- Responsive layout for desktop and mobile

Important limitations:
- This is a front-end prototype. Login, server-side storage, teacher accounts, live classes, file uploads, and real grades are not connected to a backend.
- Demo information is fictional and stored only in the current browser page.
